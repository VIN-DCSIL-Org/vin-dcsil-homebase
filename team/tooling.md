# Tooling

## Version Control and CI/CD

- GitHub will be the primary version control platform.
- The team has extensive prior experience with GitHub, so collaboration is familiar and efficient.
- GitHub supports branching, pull requests, and code review in one place.
- GitHub Actions gives us built-in CI/CD for automated builds, checks, and deployments.

## Communication Platform

- Communication will happen on Slack.
- Slack supports fast team communication.
- It keeps day-to-day coordination organized.
- It works well for standups, working sessions, and end-of-day updates.

## Sprint Management

- Sprint work will be managed using GitHub Projects as a Kanban board.
- This keeps tasks visible to the whole team.
- It links work directly to issues and bugs.
- It makes it easier to trace progress back to specific lines of code.
